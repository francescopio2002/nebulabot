# Nebula Bot v1.6 — Ticket Premium

Novità:
- conferma prima della chiusura del ticket;
- richiesta feedback da 1 a 5 stelle;
- feedback automatico in DM alla chiusura;
- salvataggio delle valutazioni nel database SQLite;
- transcript HTML inviato in DM e nel canale log;
- pannello ticket completo con claim, utenti, rinomina e trasferimento.

## Avvio

```powershell
npm install
npm run build
npm run dev
```

Non è necessario ridistribuire i comandi slash passando dalla v1.5 alla v1.6.
